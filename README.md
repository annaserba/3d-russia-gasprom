# 3D Russia Gazprom Map

Интерактивная 3D-карта присутствия «Газпрома» на территории России — анимированный SVG-экран загрузки с эффектом параллакса.

## О проекте

Визуальная заставка, отображающая карту России с ключевыми регионами и городами присутствия компании. На карте размещены 10 интерактивных точек (Москва, Санкт-Петербург, Ухта, Оренбург, Уфа, Астрахань, Тюмень, Ямал, Новый Уренгой, Южно-Сахалинск) с анимированными маршрутами и 3D-эффектом наклона при движении курсора.

## Технологии

- HTML5, CSS3, ванильный JavaScript
- Инлайн SVG (векторный контур России)
- CSS-анимации и `@keyframes`
- 3D-трансформации (`perspective`, `rotateX`, `rotateZ`)
- Никаких зависимостей и сборщиков

## Запуск

Открой `index.html` в любом современном браузере.

## Структура

```
.
├── index.html       # Основной файл (SVG, разметка, JS)
├── styles.css       # Точка входа CSS
└── css/
    ├── base.css     # Переменные, сбросы, фон
    ├── scene.css    # 3D-сцена, перспектива
    ├── map.css      # Карта, маршруты, точки
    ├── ui.css       # Всплывающие подсказки
    └── animations.css # Ключевые кадры анимаций
```
